• Project description
-
This system is an equipment borrowing system where students or borrowers can borrow
an item from the school. This system is made to make borrowing an equipment easier by
providing a clear and organized catalog for users to browse. BorrowBuddy is your
companion in every moment of your college life. It makes borrowing an item much more
convenient and easier.

• Features
-
Users can view and browse the page for items they can borrow.
-
Proper status labeling for items such as “Available” and “Unavailable”
.
-
Students/borrowers can send a request form to borrow an item, and admins can approve
or reject the request.
-
Users can login or sign up in the system.
-
Proper authentication for user levels.
• Installation/setup instructions
-
Users first need to register to properly set up their accounts in the database.
-
After registration, users can then proceed to login to their account and enter the system.
-
After logging in, students/borrowers can browse the catalogs for different items. They
can also view the different sections such as announcements, events, and their borrowed
history.
-
If students want to borrow an item, they need to send in a request form first. They need
to fill up the required information to be submitted to the administrators.
-
After getting approved, students/borrowers can now proceed to fetch the item from the
administrators in their respective storage.
-
For admins, they can manage the inventory of items and approve or reject borrowing
requests. These users can add, edit, or delete items or users. They can also announce
and set up an event.
